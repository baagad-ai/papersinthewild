## Future projects (add as you grow)

After Papers in the Wild is humming (week 6+), consider adding 1-2 of these:

### Project candidates

- **Email course** — "5 days to understanding AI research" free email course (lead magnet for freelance biz)
- **Open-source contributions** — contribute to dair-ai or similar marketing-related repos
- **Mock campaign teardowns** — public audits of well-known brands' marketing
- **AI marketing tools experiments** — test new tools (ChatGPT ads, AI SEO, etc.) and publish results

### Selection criteria
- Each project must exercise a curriculum track
- Each project must produce publishable content (no notebook experiments)
- Each project must NOT distract from Papers in the Wild weekly cadence

## How to add a new project

1. Create `projects/{slug}/` folder
2. Write `README.md` with: brief, goals, success criteria, weekly cadence
3. Add link in this file under "Active projects"
4. Update `journal/weekly/` to track its milestones

## Project archiving

When a project completes or is abandoned:
1. Move to `projects/archive/{slug}/`
2. Write retrospective in `projects/archive/{slug}/retro.md`
3. Update this README

Never delete — abandoned projects are lessons too.

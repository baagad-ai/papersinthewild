## How an episode is made

See [`pipeline.md`](./pipeline.md) for the 7-stage workflow:

1. **FETCH** — pick a paper from dair-ai
2. **READ** — Claude reads, explains, takes notes
3. **IDEATE** — 3 candidate use cases, scored
4. **BUILD** — try the use case, capture receipts
5. **WRITE** — blog (MDX) + LinkedIn + IG carousel (all on-brand per [`BRAND.md`](./BRAND.md))
6. **SHIP** — publish to GitHub Pages + LinkedIn + IG
7. **MEASURE** — T+24h, T+7d, T+30d metrics
